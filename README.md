# 📝 To-Do List Application

A simple and interactive **To-Do List web application** built using **HTML, CSS, and vanilla JavaScript**.  
This project was created to practice **JavaScript fundamentals**, especially DOM manipulation and event handling, without using any external libraries or frameworks.

---

## ✨ Features

- ➕ Add new tasks
- ✏️ Edit existing tasks
- ✔️ Mark tasks as completed (toggle functionality)
- ❌ Delete tasks
- 🎨 Visual indication for completed tasks using CSS

---

## 🧠 What I Learned

- Creating and manipulating DOM elements dynamically
- Handling events on dynamically created elements
- Using CSS classes to manage UI state
- Implementing basic CRUD operations in JavaScript
- Debugging common JavaScript and browser-related issues

---

## 🛠️ Tech Stack

- **HTML** – Page structure  
- **CSS** – Styling and visual feedback  
- **JavaScript** – Application logic and interactivity
